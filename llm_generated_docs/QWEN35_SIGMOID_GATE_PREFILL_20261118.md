# Qwen3.5 prefill 输出 sigmoid 门控并行化

运行时基线 `35da823`，native `dfd37e4`。Qwen3.5-4B C7 在每个完整注意力层结束时对输出逐元素乘以 sigmoid(gate)。新版按 token 行分派给已有 Rayon 池。每个元素保留原版的 FP32 sigmoid 和乘法，单行或单线程时直接沿用串行函数。

## 门控耗时与 CPU 成本

另用相同的 512-token prefill、随后 1 步 decode 采集 Perfetto，每版三轮。按门控发生在 GQA 核心之后的位置分离 32 次输出门控，不包含投影、Q/K Norm 或 RoPE。外部采样器固定在小核，每约 12 ms 读取进程所有线程的累计 CPU ticks，在 prefill 起止点插值。核秒为累计执行时间，四大核平均占用以每轮 wall time 的四倍为分母。
