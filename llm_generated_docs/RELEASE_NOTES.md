# v0.10.0

- 新增 MiniCPM-V 4.7 35B-A3B 文本推理与 DSpark 投机解码，支持标准 compressed-tensors W4A8/W8A8 混合量化 checkpoint；视觉暂未接入。
- 新增 MoE 专家常驻和磁盘流式加载模式，支持打包专家库复用、按比例设置逐层 NPU 缓存、LES 预取及异步读取与导入。通过逻辑 prefill chunk、专家分组读取和冷专家流水执行降低重复读盘与等待。
- 新增可选的低权重专家跳过，减少专家读盘和计算；这是近似推理选项，默认关闭，可能改变模型输出。
- 改进 Qwen3.5 长上下文内存布局，先分配 KV 并为执行工作区预留 IOVA 空间，补充最高 64K 上下文的吞吐与峰值 RSS 数据。
- 新增 `--compress-w8a8` 无损权重压缩，仅在编码后更小时使用压缩 tile；复用 prefill/decode 工作区并在阶段切换时释放多余缓冲。
- `run`、`chat` 和 `serve` 新增 prefill 进度、缓存命中、ETA、decode 速度及投机解码统计；缺少适用调优缓存时提示对应的调优方式。
- 新增按模型家族裁剪构建与自定义交付名称，包内 `build-info.json` 记录实际版本和启用家族；加入配置驱动的单板/多板自动回归工具。
- 更新 NPU 算子库，修复 MoE 槽位所有权、零路由同步和流式加载生命周期问题；同步中英文 README 的模型支持、性能数据与使用示例。
