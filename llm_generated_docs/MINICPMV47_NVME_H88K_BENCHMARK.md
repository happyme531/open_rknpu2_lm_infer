旧板 64 槽、约 6.481GiB 的 NFS 历史结果为 pp 21.878、tg 3.905 tok/s；本轮最大正式档为 56 槽，容量不同，不计算同槽数速度比值。

两块板的内存容量与内核不同，历史比较不是同板替换存储的因果 A/B；两轮使用同一个冻结 ARM64 二进制、同一模型与输入、相同 CPU/NPU/DDR 目标频率。

## 真实专家序列的纯 IO 并发回放

## 测量口径

- HINLINK H88K，总内存 7.498 GiB；内核 6.1.115-vendor-rk35xx，NPU 驱动 0.9.8。
- Predator SSD GM7 512GB，链路 8.0 GT/s PCIe ×4，ext4 `/mnt/nvme`。模型和专家文件均位于本地 SSD。
- 同一无 SQ QQQ CT 模型，路由专家 gate/up/down 全部 W4A8，共享专家及 LM head W8A8。
- CPU4–7 2.4GHz、NPU mask7 1GHz、DDR2112MHz；每次独立进程、专家窗口初始为空。
- pp 不含最终 LM head，tg 含逐 token LM head；模型加载、预分配和输出文件写入不计入 pp/tg。
- 复用 2026-10-21 缓存容量实验的冻结二进制，16MiB bank 分块，未改调度或 production 源码。
- 原生专家记录 1,597,440 B，O_DIRECT，单 IO worker；记录在主机缓冲区就绪后仍需导入 NPU。
- 峰值 RSS 包含约 121MiB 完整 logits 缓冲；所有正式样本与历史常驻基线 logits 逐字节一致。
- 开关预取为同板配对对照；每档两次。Trace 独立运行，不计入速度均值。
- 必要读量=冷专家数×记录大小；额外读量=完成读取字节−必要读量，包含读完后取消的预取。
- IO 服务、导入、计算与等待有重叠，不能相加。MB 为十进制，GiB 为二进制。
- 正式计时阶段测速进程 VmSwap 最大值 64828 KiB；最小 MemAvailable 1.039 GiB。全系统后台 swap 计数单独保留，不据此判定测速进程换页。
- 当前转接链路仍有可纠正 PCIe 错误和偶发配置读全 ff；本次结果代表当前连接状态。每次运行保留前后链路状态、配置采样及 AER 状态。
- 完整时钟还原结果、250ms 内存/块设备采样、逐 token 耗时及原始统计保存在同名 evidence 目录。
